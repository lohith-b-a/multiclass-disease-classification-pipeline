Model Training and Comparison for Multiclass Disease Classification¶

Model Training and Comparison for Multiclass Disease Classification Objective

This notebook focuses on training and comparing machine learning models for multiclass disease classification using the processed dataset prepared in the previous stage.

The main objectives are to:

establish a baseline benchmark, train a range of models from different model families, evaluate performance using metrics appropriate for imbalanced multiclass classification, compare models under a consistent data split and evaluation framework, identify the model that appears most suitable for subsequent analysis based on the observed results.

All preprocessing steps were completed in the previous notebook to maintain a clear separation between data preparation and model development.

This model predicts the most frequent class and does not learn from the feature set. It provides a useful reference for assessing whether trained models capture meaningful symptom–disease relationships.

Given the class imbalance, baseline evaluation focuses on:

Accuracy as a general reference, Weighted F1-score to reflect overall class-weighted performance, Macro F1-score to assess performance across all classes equally.

In this setting, Macro F1 is the most informative metric for judging whether a model performs beyond majority-class prediction.

Reusable Evaluation Function¶

To ensure consistent comparison across models, a reusable evaluation function is used.

Each model is trained and evaluated under the same procedure, with performance reported using:

Accuracy Weighted F1-score Macro F1-score

Because the task is multiclass and imbalanced, Macro F1 is treated as the most informative comparison metric, while Accuracy and Weighted F1 provide supporting context.

In [11]:
def evaluate_model(model, X_train, y_train, X_val, y_val, model_name):
    # Train model
    model.fit(X_train, y_train)

    # Predict
    y_val_pred = model.predict(X_val)

    # Metrics
    accuracy = accuracy_score(y_val, y_val_pred)
    f1_weighted = f1_score(y_val, y_val_pred, average="weighted")
    f1_macro = f1_score(y_val, y_val_pred, average="macro")

    # Print summary (NEW)
    print(f"\n{model_name}")
    print(f"Accuracy: {accuracy:.4f}")
    print(f"Weighted F1: {f1_weighted:.4f}")
    print(f"Macro F1: {f1_macro:.4f}")

    return {
        "Model": model_name,
        "Accuracy": accuracy,
        "Weighted F1": f1_weighted,
        "Macro F1": f1_macro
    }, y_val_pred

Model Comparison Strategy¶

A range of models from different families was evaluated to assess how various learning approaches perform on the disease classification task.

The selected models include:

Linear models: Logistic Regression, Linear SVM Distance-based model: K-Nearest Neighbors (KNN) Tree-based model: Random Forest Boosting model: XGBoost Neural network model: MLPClassifier

This selection allows comparison across models with different assumptions about the data, including linear separability, local similarity, and non-linear feature interactions.

All models are trained and evaluated using the same data split and evaluation metrics to ensure a consistent and fair comparison.

The selected models represent different learning assumptions about the relationship between symptoms and diseases.

  • Linear models (Logistic Regression, SVM):

Assume that diseases can be separated using linear combinations of symptoms. These models are efficient and provide a strong baseline for high-dimensional data.

  • Distance-based model (KNN):

Assumes that patients with similar symptom patterns belong to similar disease classes. This evaluates whether local similarity is sufficient for classification.

  • Tree-based model (Random Forest):

Captures non-linear relationships and interactions between symptoms, which is important when diseases are defined by combinations of features. Boosting model (XGBoost):

  • Focuses on improving performance by sequentially correcting errors, often providing strong results in structured datasets.
  • Neural network (MLP):

Learns complex, non-linear patterns without predefined assumptions about feature relationships.

Model Selection Process¶

Model configurations used in this notebook were informed by prior experimentation conducted in a separate exploratory notebook.

Different model families and parameter settings were evaluated to identify stable and reasonable configurations. Based on those results, a subset of representative models was selected for structured comparison in this stage.

The goal of this notebook is not exhaustive tuning, but consistent comparison across models using a fixed experimental setup.

Logistic Regression Model¶

Logistic Regression is used as the first trained model to establish a strong and interpretable baseline.

It assumes that diseases can be distinguished using linear combinations of symptom features, which is suitable given the binary nature of the input variables.

To address class imbalance, class weighting is applied (class_weight="balanced"), ensuring that minority disease classes contribute more during training.

The maximum number of iterations is increased to ensure convergence.

Linear SVM Model¶

A Linear Support Vector Machine (SVM) is used as an alternative linear classification approach.

Class weighting is applied to address imbalance, and the regularization parameter is set to balance margin size and classification performance.

This model allows comparison between probability-based and margin-based linear methods.

Model Comparison Summary¶

The evaluated models show clear differences in performance across both overall accuracy and balanced classification.

  • XGBoost achieves the highest performance across all metrics, with the strongest Macro F1, indicating the best balance across classes
  • Neural Network (MLP) provides the second-best performance, demonstrating the importance of non-linear modeling
  • Logistic Regression and Linear SVM establish strong linear baselines, but are limited in capturing complex relationships
  • Random Forest improves overall accuracy but does not achieve strong balanced performance
  • KNN performs the weakest, likely due to high dimensionality and overlapping symptom patterns

Given the evaluation strategy, where Macro F1 is the primary metric, XGBoost provides the most consistent performance across all classes.

The results suggest that:

  • The relationship between symptoms and diseases is non-linear and interaction-driven
  • Models that iteratively refine decision boundaries (e.g., boosting) are more effective in this setting
  • Simpler models capture baseline structure but are insufficient for optimal performance

Why XGBoost Performed Better¶

XGBoost outperforms other models due to its underlying gradient boosting framework and several key properties:

  • Sequential Error Correction: Unlike bagging methods such as Random Forest, XGBoost builds trees sequentially, where each new tree focuses on correcting the errors of the previous ones. This allows the model to better learn difficult patterns, especially in minority classes.

  • Ability to Model Complex Relationships: XGBoost effectively captures non-linear relationships and feature interactions, which are likely present in this dataset. This explains its advantage over linear models such as Logistic Regression and SVM.

  • Regularization Mechanisms: XGBoost includes built-in regularization (L1/L2), which helps prevent overfitting while maintaining high model capacity.

  • Robustness to Feature Scaling: Unlike Neural Networks, XGBoost does not require feature scaling and is less sensitive to feature distributions, making it more stable in practice.

  • Handling of Imbalanced Data: While not explicitly designed for imbalance, the boosting process naturally emphasizes harder-to-classify samples, which often correspond to minority classes. This contributes to its higher Macro F1 score.

Comparison with Other Models¶

  • The Neural Network demonstrates moderate performance but is more sensitive to class imbalance and data size, limiting its ability to generalize across all classes.
  • Random Forest performs хуже than XGBoost, indicating that bagging alone is less effective than boosting for this problem.
  • Logistic Regression and SVM are constrained by linear decision boundaries, which are insufficient for capturing the complexity of the data.
  • KNN is negatively impacted by class imbalance and high dimensionality, resulting in the weakest performance.

Model Selection Summary¶

  • XGBoost outperforms all models across Accuracy, Weighted F1, and Macro F1
  • Linear models provide strong baseline performance but are limited by linear assumptions
  • Tree-based models improve accuracy but do not sufficiently address class imbalance
  • XGBoost achieves the best balance between overall performance and class-level consistency

Conclusion¶

This notebook presented the training and evaluation of multiple machine learning models for multiclass disease classification. A range of models, including linear, distance-based, tree-based, ensemble, and neural network approaches, were compared using consistent training and validation splits.

Among the evaluated models, XGBoost achieved the strongest performance, particularly in terms of Macro F1-score, which was selected as the primary metric due to class imbalance. This indicates that XGBoost provides the most balanced performance across the different disease classes.
